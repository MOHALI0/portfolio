# Mohammed Ali Saleh Al Sidran — Developer Portfolio

A modern, high-performance developer portfolio built from scratch with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**. Designed following the minimalist, island-card aesthetic benchmark inspired by modern SaaS and elite digital studio portfolios.

---

## 🚀 Key Highlights & Architectural Features

- **Component Island Layout System**: Every section is cleanly framed inside a refined island container (`portfolio-island`) with subtle borders, diffused elevation shadows, and responsive corner radiuses (`rounded-[32px]` / `rounded-[40px]`).
- **Developer Identity & Hero Hook**:
  - Live availability pill with pulsing indicator (`● Available for new opportunities`).
  - Mohammed's authentic portrait (`/avatar.jpg`) adorned with an interactive greeting badge (`Mohammed 👋`).
  - Prominent academic highlight (**4.80 / 5.00 GPA** at Jazan University) and **FinTech Hackathon Lead** credentials.
  - Direct 1-click email copy with visual feedback ("Copied! ✨") and instant PDF CV download.
- **Trust & Credibility Strip**: Validated partners and milestones (Tuwaiq Academy, Alinma Bank, Google Developer Student Clubs, Jazan University, Coursera).
- **Interactive Projects Showcase**:
  - Multi-category filtering: `All`, `FinTech & Web`, `Systems & Python`, `Data Science & AI`.
  - Detailed project cards with gradient banner headers, role tags, architectural highlights, and live demo / source links.
  - **Interactive Architecture Modal** with deep-dive technical specs, problem statement, and key deliverables.
- **Visual Competencies & Skills Matrix**:
  - 4-pillar service breakdown mirroring elite design studio standards.
  - Interactive skill category switcher with proficiency ratings and verified tags.
  - Smooth infinite marquee ticker highlighting modern stack keywords.
- **Chronological Experience Timeline**:
  - Lead Developer at Tuwaiq & Alinma Bank FinTech Hackathon.
  - Event Organizer & Core Member at Google Developer Student Clubs (GDSC).
  - B.Sc. in Computer Science at Jazan University (4.80 GPA).
  - 130+ Certified Community Volunteer Hours.
  - Coursera Data Science in Python Certification.
- **Dual Theme Support (Dark & Light Mode)**:
  - Default adapts to system preferences, switchable via the header toggle.
  - Light mode: Pure white card surfaces on warm slate backdrops.
  - Dark mode: Deep obsidian surfaces with subtle emerald/cyan accents.
- **Interactive Contact & Messaging System**:
  - Quick action pills for direct email, WhatsApp, and LinkedIn connection.
  - Interactive contact form with validation, real-time submission simulation, and success toast.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **UI & Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/) + Custom SVG brand marks
- **State & Theme**: React Context API (`ThemeProvider`) with persistent local storage
- **Animations**: CSS Keyframe animations & transitions

## 📦 Getting Started

### Prerequisites

- Node.js `v18+` or `v20+` or `v24+`
- npm or pnpm

### Development Server

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

Create an optimized production build:

```bash
npm run build
npm run start
```
